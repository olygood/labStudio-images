# Prompt System

Espace dédié à la structure des prompts, à leur composition et aux règles communes du laboratoire.

## Documents
- [grammar.md](grammar.md) — grammaire de prompt proposée.

## Principes
- Séparer le sujet, le contexte, le style, la composition, la lumière et les contraintes.
- Garder une copie du prompt réellement envoyé.
- Distinguer les paramètres natifs des instructions en langage naturel et des techniques expérimentales.
