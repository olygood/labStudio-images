# Angles de caméra

Vocabulaire de référence pour les angles de prise de vue. Les résultats dépendent du modèle et de la formulation ; ces termes ne garantissent pas un contrôle optique exact.

| Terme | Description / intention |
|---|---|
| Eye level | Caméra à hauteur du sujet |
| High angle | Vue plongeante, caméra au-dessus du sujet |
| Low angle | Contre-plongée, caméra sous le sujet |
| Bird's-eye view | Vue très élevée, presque verticale |
| Worm's-eye view | Vue extrêmement basse vers le haut |
| Dutch angle | Horizon incliné pour créer une tension visuelle |
| Over-the-shoulder | Vue par-dessus l'épaule d'un personnage |
| Profile view | Sujet vu de profil |
| Three-quarter view | Sujet orienté en trois-quarts |
| Front view | Vue frontale |
| Rear view | Vue arrière |
