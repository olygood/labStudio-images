# Atmospheric Silhouette

Style visuel basé sur des silhouettes fortes, des contre-jours et une atmosphère marquée.

## Contenu
- `prompt.md` : prompt de référence et variantes.
- `References/` : images d'inspiration et références externes.
- `Images/` : images générées et sélectionnées.
- `Experiments/` : essais documentés et résultats.

## Convention :
Conserver le prompt exact, le modèle utilisé, les paramètres disponibles et les observations pour chaque essai. Respecter les licences et noter la source des références.

**Style graphique:**	Minimalist Stylized Illustration
**Technique de construction:**	Shape-Based Illustration
**Traitement des couleurs:**	Flat Color Rendering
