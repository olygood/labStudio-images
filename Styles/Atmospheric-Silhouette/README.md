# Analyse des styles artistiques — Référence

## 1. Historique des appellations proposées

Pour les mêmes cinq images de référence, sept appellations différentes ont été proposées :

1. Atmospheric Silhouette
2. Atmospheric Silhouette Illustration
3. Atmospheric 2D Illustration
4. Minimalist Stylized 2D Illustration
5. Minimalist Stylized Illustration
6. Flat Shape Illustration
7. Flat Illustration

Ces appellations ont été proposées sans analyse suffisamment approfondie entre chaque changement.

**Conclusion :** une succession d'hypothèses ne constitue pas une méthode de classification fiable.

---

## 2. Les quatre notions à distinguer

| Notion | Exemple | Rôle |

| **Style graphique** | Flat Design, Minimalism | Manière de représenter les formes |
| **Technique graphique** | Shape-Based Construction | Manière de construire les objets |
| **Effet visuel** | Atmospheric Perspective | Profondeur, brume, atmosphère |

---

## 3. Principe de classification

Pour analyser une image, il faut distinguer :

- **La discipline artistique :** quel type de travail est réalisé ?
- **Le style graphique :** comment l'image est-elle représentée ?
- **Les techniques graphiques :** comment les formes sont-elles construites ?
- **Les effets visuels :** quels traitements sont appliqués à l'image ?

Ces quatre notions ne doivent pas être confondues.

---

## 4. Règle pour labStudio-images

**Ne pas attribuer un nom de style définitif sans analyse suffisante des images de référence.**

Avant de valider une classification :

1. Examiner les images originales.
2. Identifier les caractéristiques graphiques communes.
3. Distinguer style, discipline, techniques et effets.
4. Vérifier le statut des termes artistiques employés.
5. Documenter la classification retenue.

**Un changement de classification ne doit pas entraîner automatiquement un changement de nom des dossiers GitHub.**
